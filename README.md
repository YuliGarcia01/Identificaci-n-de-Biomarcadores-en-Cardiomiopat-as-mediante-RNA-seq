# Identificacion-de-Biomarcadores-en-Cardiomiopatias-mediante-RNA-seq
Este proyecto analiza datos públicos de RNA-seq de tejido cardíaco sano y enfermo. El objetivo es identificar genes diferencialmente expresados y rutas moleculares alteradas en la insuficiencia cardíaca mediante herramientas bioinformáticas en R (DESeq2), descubriendo biomarcadores clave para el diagnóstico de cardiopatías.
